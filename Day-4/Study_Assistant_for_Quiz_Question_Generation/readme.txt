# Study Assistant Quiz Generator

This notebook helps you quickly generate study summaries and multiple-choice quiz questions from your own study materials.

## Features
- **Upload PDF or Word documents** (or paste text directly)
- **Automatic text extraction** from your files
- **Summarizes key points** from your study material
- **Generates multiple-choice quiz questions** (with answers and explanations)
- **Option to save the quiz and summary** to a text file

## How to Use
1. **Open the notebook in Google Colab.**
2. **Set up your Gemini API key** as a Colab secret (`GOOGLE_API_KEY`).
3. **Run all cells** to initialize the assistant.
4. **Choose to upload a file or paste text.**
5. **Get a summary and generate quiz questions.**
6. **Optionally, save the results to a file.**

**Supported formats:** PDF (.pdf), Word (.docx, .doc), or direct text input.
